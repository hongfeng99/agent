# Chapter 14：自动化深度研究智能体

本项目用于实现一个简化版 Deep Research Agent。

## 项目目标

用户输入一个研究主题后，系统自动完成：

1. 研究任务规划；
2. 网络资料搜索；
3. 搜索结果整理；
4. 子任务总结；
5. 研究笔记保存；
6. 最终报告生成。
